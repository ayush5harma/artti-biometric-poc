6. Production Edge Cases Hardened & Verified

Every edge case identified for real-world customer APKs has been implemented and verified in the E2E suite.

1. Original AppComponentFactory Delegation

Customer apps using AndroidX/Hilt declare their own android:appComponentFactory. LSPAppComponentFactoryStub reads assets/lspatch/original_app_component_factory.txt and delegates all 6 instantiate* lifecycle methods to the original factory (verified: origFactoryDelegated=true).

2. Constructor-Free JNI AllocObject Fallback

BiometricPrompt$AuthenticationResult has a @hide constructor. nativeCreateAuthenticationResult probes API 29–37 (CryptoObject,int)V, API 28 variants, and falls back to JNI AllocObject + field population so future Android 18+ constructor changes cannot break PASS (verified: allocFallbackType=2).

3. Un-Enrolled Device & Legacy FingerprintManager

Cloud devices often have no enrolled biometrics. Breakpoints at offset 0 force BiometricManager.canAuthenticate() -> 0 (BIOMETRIC_SUCCESS) and FingerprintManager.isHardwareDetected() / hasEnrolledFingerprints() -> true, plus intercept legacy FingerprintManager.authenticate (verified: canAuth=0 fpReady=true/true).

4. Memory + Binder FLAG_DEBUGGABLE Scrub

In addition to scrubbing mBoundApplication.appInfo and LoadedApk.mApplicationInfo, LSPApplication disables the ApplicationPackageManager cache and installs an IPackageManager proxy so Binder queries also see FLAG_DEBUGGABLE == 0 (verified: appSeesDebuggable=false pmSeesDebuggable=false).
